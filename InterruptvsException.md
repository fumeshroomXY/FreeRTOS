# Interrupt
An interrupt is a signal from **hardware peripherals** that tells the CPU:  
“Something happened. Stop what you're doing and handle me.”

Examples:
- UART received data
- Timer overflow
- GPIO pin changed
- ADC conversion finished

# Exception
An exception is an event generated by the **CPU itself**.
It happens because:
- An error occurred
- A system-level event occurred
- A special instruction was executed

Examples (ARM Cortex-M)
- Reset
- NMI
- HardFault
- MemManage Fault
- UsageFault (e.g., divide by zero)
- PendSV
- SysTick

# Comparison
|              | Interrupt               | Exception                      |
| ------------ | ----------------------- | ------------------------------ |
| Source       | External hardware       | CPU internal event             |
| Example      | UART RX, Timer overflow | Divide by zero, HardFault      |
| Triggered by | Peripheral              | CPU core                       |
| Purpose      | Handle I/O events       | Handle errors / system control |


# Why This Matters in RTOS
In FreeRTOS (on Cortex-M):
- **SysTick** → Generates periodic tick interrupt
- **PendSV** → Used for context switching
- **SVC** → Used to start scheduler

These are **exceptions**, not external interrupts.

On ARM Cortex-M: **Interrupts are a type of exception.**

The architecture treats everything as an exception.

So RTOS uses CPU exceptions as control mechanisms.
